# ZshrcEditor

A lightweight macOS SwiftUI editor for `~/.zshrc`.

Features:

- code editing with line numbers and shell syntax highlighting
- quick search with match navigation
- quick-jump sidebar for exports, variables, and aliases
- save with `source ~/.zshrc` validation in a child `zsh` process

Open [ZshrcEditor.xcodeproj](/Users/cxy/Desktop/CXY/zshrc/ZshrcEditor.xcodeproj) in Xcode to run the app.
